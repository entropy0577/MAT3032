### Chapter 1: Groups

#### §1.1 Historical Overview and Group Fundamentals

The chapter opens with a historical survey tracing the origins of group theory from Euler (1761) through Gauss, Lagrange, Cauchy, Galois, Cayley, Sylow, Lie, von Dyck, and Burnside to the classification of finite simple groups (completed 1981). Ring theory history is also covered, from Fermat's Last Theorem through Hamilton's quaternions, Cayley's matrices, Dedekind's ideals, and the Wedderburn–Artin–Jacobson structure theorems.

**Core definitions reviewed:**
- **Group** $(G, *)$: set with associative binary operation, identity $e$, and inverses
- **Abelian group**: commutative group
- **Subgroup test**: $H \leq G$ iff $ab^{-1} \in H$ for all $a, b \in H$
- **Lagrange's Theorem**: if $H \leq G$ and $G$ finite, then $|H|$ divides $|G|$
- **Element order**: $o(a)$ = smallest $k \in \mathbb{N}$ such that $a^k = e$; $o(a) \mid |G|$
- **Homomorphism, kernel, image, injectivity, surjectivity, isomorphism, automorphism**

**Standard group families:**
- **Cyclic groups** $C_n$: generated by single element $g$ with $g^n = e$; isomorphic to $(\mathbb{Z}_n, +_n)$; number of generators is $\varphi(n)$ (Euler's totient function); unique subgroup of order $d$ for each divisor $d$ of $n$
- **Groups of units** $U_n$: units of $(\mathbb{Z}_n, \times_n)$, order $\varphi(n)$
- **Matrix groups**: $GL(n, R)$, $SL(n, R)$; the subgroup $R_n$ of upper triangular matrices with units on the diagonal, having order $n\varphi(n)^2$
- **Symmetric groups** $S_n$: permutations under composition, order $n!$; cycle notation, transpositions, sign function, **alternating group** $A_n$ (order $n!/2$)
- **Dihedral groups** $D_n$: symmetries of regular $n$-gon, order $2n$
- **Direct products** $G_1 \times \cdots \times G_n$; $C_m \times C_n \cong C_{mn}$ iff $\gcd(m, n) = 1$

#### §1.2 Generators and Presentations

- **Generating set** $S$ for a group $G$: $\langle S \rangle$ is the smallest subgroup containing $S$
- **Presentation** $\langle S : R \rangle$: generators and defining relations
- **Examples**: $C_n = \langle g : g^n = e \rangle$; Klein 4-group $V = \langle a, b : a^2 = b^2 = e, aba = b \rangle$; $D_n = \langle \sigma, \tau : \sigma^n = \tau^2 = \iota, \sigma\tau\sigma = \tau \rangle$

**Classification of groups of order 8:**  
The notes prove that any non-abelian group of order 8 is isomorphic to either $D_4$ or $Q_4$ (the quaternion group). Combined with the three abelian groups ($C_8$, $C_4 \times C_2$, $C_2 \times C_2 \times C_2$), there are exactly **five** groups of order 8 up to isomorphism.

**Derivation:** If $G$ is non-abelian of order 8, all non-identity elements have order 2 or 4 (by Lagrange). At least one has order 4 (else $G$ is abelian). Pick $a$ of order 4, $b \notin \langle a \rangle$. Then $G = \{e, a, a^2, a^3, b, ab, a^2b, a^3b\}$. Since $b^2 \in \langle a \rangle$ and $b^4 = e$, either $b^2 = e$ (giving $D_4$) or $b^2 = a^2$ (giving $Q_4$).

**Dicyclic groups** $Q_n$: order $2n$, presentation $\langle a, b : a^n = e, b^2 = a^{n/2}, aba = b \rangle$. $Q_4$ (quaternion group, order 8) has Cayley table given explicitly.

#### §1.3 Cosets, Products, and Quotient Groups

**Cosets:**
- Left coset $aH = \{ah : h \in H\}$, right coset $Ha = \{ha : h \in H\}$
- Cosets partition $G$; index $[G:H] = |G|/|H|$

**Normal subgroups** ($H \trianglelefteq G$): $aH = Ha$ for all $a \in G$.
- Equivalent: $aHa^{-1} = H$ for all $a \in G$
- Any subgroup of index 2 is normal
- Kernels of homomorphisms are normal

**Proposition 1.1** (checking normality via generators): $H \trianglelefteq G$ iff $ghg^{-1} \in H$ for all $g$ in a generating set for $G$ and all $h$ in a generating set for $H$.

**Proposition 1.2** (conjugation identities): For $a, b \in G$ and $n \in \mathbb{N}$:
1. $(bab^{-1})^n = ba^n b^{-1}$
2. If $bab^{-1} = a^r$ then $b^n ab^{-n} = a^{r^n}$

**Proposition 1.3** (products of subgroups):
1. $HJ$ is a subgroup iff $JH = HJ$
2. If $H \trianglelefteq G$ or $J \trianglelefteq G$ then $HJ \leq G$
3. If both $H, J \trianglelefteq G$ then $HJ \trianglelefteq G$

*Proof of (i):* Uses the subgroup test. If $HJ \leq G$, then for $h^{-1}j^{-1} \in HJ$ we get $(h^{-1}j^{-1})^{-1} = jh \in HJ$, so $JH \subseteq HJ$; similarly $HJ \subseteq JH$. Conversely, if $JH = HJ$ then the subgroup test shows closure under $ab^{-1}$.

**Proposition 1.4** (order of product): $|HJ| = \frac{|H| \cdot |J|}{|H \cap J|}$ (proof deferred to Chapter 2 using the orbit-stabiliser theorem).

**Proposition 1.5** (internal direct product): If $G = HJ$, $H \cap J = \{e\}$ then:
1. Each element has a unique expression $hj$
2. $H, J \trianglelefteq G$ iff $hj = jh$ for all $h, j$; then $G \cong H \times J$

*Proof of uniqueness:* If $hj = h'j'$ then $h'^{-1}h = j'j^{-1} \in H \cap J = \{e\}$, so $h = h'$ and $j = j'$.

*Proof of commutativity ↔ normality:* If both are normal, the commutator $hjh^{-1}j^{-1}$ lies in both $H$ and $J$, hence equals $e$. Conversely, if elements commute, then $Ha = Hhj = Hj = jH = hjH = aH$, so $H \trianglelefteq G$.

**Quotient groups** $G/H$: when $H \trianglelefteq G$, the cosets $\{aH : a \in G\}$ form a group with $(aH)(bH) = abH$.

**First Isomorphism Theorem**: If $\phi: G_1 \to G_2$ is a homomorphism, then $\ker\phi \trianglelefteq G_1$ and $G_1/\ker\phi \cong \phi(G_1)$.

**Proposition 1.7** (Subgroup Correspondence Theorem): The subgroups of $G/N$ are precisely $H/N$ for subgroups $H$ of $G$ containing $N$. Furthermore, $H/N \trianglelefteq G/N$ iff $N \trianglelefteq H \trianglelefteq G$, and then $(G/N)/(H/N) \cong G/H$ (the **Third Isomorphism Theorem**).

*Proof:* Establishes a bijection between subgroups of $G/N$ and subgroups of $G$ containing $N$. Uses the map $\psi: G/N \to G/H$ defined by $\psi(gN) = gH$, which is well-defined and surjective with kernel $H/N$.

**Proposition 1.8**: If $G/N$ is cyclic, then $G$ has a subgroup isomorphic to $G/N$.

*Proof:* If $gN$ generates $G/N$ with order $m$, and $g$ has order $r$ in $G$, then $m \mid r$, so $r = km$. Then $g^k$ has order $m$ in $G$, giving $\langle g^k \rangle \cong G/N$.

#### §1.4 Finite Abelian Groups

**Proposition 1.9**: If an abelian group $G$ has generating set $\{g_1, \ldots, g_k\}$ and $\gcd(m_1, \ldots, m_k) = 1$, then $G$ has a $k$-element generating set containing $g_1^{m_1} \cdots g_k^{m_k}$.

**Proposition 1.10** (Fundamental Theorem of Finite Abelian Groups): Every finite abelian group is isomorphic to a direct product of cyclic groups in two canonical forms:
1. **Primary decomposition**: $G \cong C_{p_1^{n_1}} \times \cdots \times C_{p_r^{n_r}}$ (prime power orders)
2. **Invariant factor decomposition**: $G \cong C_{q_1} \times \cdots \times C_{q_s}$ where $q_i \mid q_{i+1}$

*Proof sketch:* By induction on the size of the smallest generating set. The key step: if $\langle g_1 \rangle \cap H$ is non-trivial (where $H = \langle g_2, \ldots, g_k \rangle$), one constructs an element $x$ of order less than $o(g_1)$ in a $k$-element generating set, contradicting minimality.

**Examples:**
- 5 groups of order 8: $C_8$, $C_4 \times C_2$, $C_2^3$, $D_4$, $Q_4$
- 3 abelian groups of order 54: $C_{54}$, $C_3 \times C_{18}$, $C_3 \times C_3 \times C_6$
- 4 abelian groups of order 252

#### §1.5 Automorphisms and Semi-Direct Products

**Proposition 1.11**: $\text{Aut}(C_n) \cong U_n$, with $|\text{Aut}(C_n)| = \varphi(n)$. The automorphisms are $\psi_m: g \mapsto g^m$ for $\gcd(m, n) = 1$.

*Proof:* Defines $\theta: U_n \to \text{Aut}(C_n)$ by $\theta(m) = \psi_m$, shows it's a group isomorphism. $\psi_m$ is bijective iff $m \bmod n$ is a unit of $\mathbb{Z}_n$.

**Inner automorphisms**: $\gamma_a: x \mapsto axa^{-1}$; $\text{Inn}(G) \trianglelefteq \text{Aut}(G)$; $G/Z(G) \cong \text{Inn}(G)$.

**Semi-direct product** $H \rtimes J$: when $G = HJ$, $H \cap J = \{e\}$, $H \trianglelefteq G$ (but $J$ need not be normal). $J$ acts on $H$ by conjugation: $\gamma_j(h) = jhj^{-1}$.

**Example (groups of order 12):** With $H \cong C_3$ and $J \cong C_4$, $H \trianglelefteq G$: conjugation by $j$ maps $h$ to $h$ (giving $C_{12}$) or $h^2$ (giving a non-abelian group with presentation $\langle h, j : h^3 = j^4 = e, hjh = j \rangle$). The case $J \trianglelefteq G$, $H \not\trianglelefteq G$ leads to a contradiction via Proposition 1.2.

### Chapter 2: Group Actions, Conjugacy, Sylow Theorems, and Simple Groups

#### §2.1 Group Actions

**Definition:** A left action of $G$ on a set $X$: $(g, x) \mapsto g(x) \in X$ with $e(x) = x$ and $g_1(g_2(x)) = (g_1g_2)(x)$.

**Key concepts:**
- **Orbit**: $O(x) = \{g(x) : g \in G\}$
- **Stabiliser**: $G_x = \{g \in G : g(x) = x\}$ (a subgroup of $G$)
- **Fixed set**: $\text{Fix}(g) = \{x \in X : g(x) = x\}$

**Proposition 2.1**: Stabilisers are subgroups of $G$.

**Proposition 2.2** (Orbit-Stabiliser Theorem): There is a bijection $g(x) \mapsto gG_x$ between $O(x)$ and left cosets of $G_x$. For finite $G$: $|O(x)| \cdot |G_x| = |G|$.

*Proof:* Shows $h(x) = g(x) \iff g^{-1}h \in G_x \iff h \in gG_x$, establishing the bijection.

**Proposition 2.3** (Orbit Decomposition Theorem): $|X| = |\text{Fix}(G)| + \sum_{i=1}^n [G:G_{x_i}]$ where the sum runs over representatives of orbits with more than one element.

**Proof of Proposition 1.4** (using group actions): $H$ acts on $G/J$ by left multiplication. The stabiliser of $J$ is $H \cap J$. The orbit of $J$ has $|HJ|/|J|$ elements. By orbit-stabiliser: $\frac{|HJ|}{|J|} \cdot |H \cap J| = |H|$.

**Proposition 2.4**: Any action of $G$ on a set of size $m$ gives a homomorphism $G \to S_m$ with kernel $\widetilde{G}_X$.

**Proposition 2.5**: A subgroup of index $m$ yields a homomorphism $G \to S_m$ with kernel contained in the subgroup.

**Proposition 2.6** (Cayley's Theorem): Every group of order $n$ is isomorphic to a subgroup of $S_n$.

**Proposition 2.7**: If $p$ is the smallest prime dividing $|G|$, then any subgroup of index $p$ is normal.

*Proof:* The homomorphism $G \to S_p$ has image dividing $p!$ and $|G|$. Since all prime factors of $|G|$ are $\geq p$, $|G/K| = p$, forcing $K = H$.

**Proposition 2.8**: Every group of order $p^2$ is abelian, isomorphic to $C_{p^2}$ or $C_p \times C_p$.

*Proof:* If no element has order $p^2$, the $p^2 - 1$ elements of order $p$ generate $p + 1$ subgroups of order $p$, each normal (by Prop 2.7). Pick any two; their product gives $G \cong C_p \times C_p$.

#### §2.2 Conjugacy

- **Conjugacy class** of $x$: $x^G = \{gxg^{-1} : g \in G\}$ (orbit under conjugation)
- **Centraliser**: $C_G(x) = \{g : gx = xg\}$ (stabiliser under conjugation)
- **Centre**: $Z(G) = \{g : gx = xg\ \forall x\}$; $Z(G) \trianglelefteq G$
- **Class equation**: $|G| = |Z(G)| + \sum_{x \in T} \frac{|G|}{|C_G(x)|}$

**Proposition 2.9**: $Z(G)$ is the union of all one-element conjugacy classes.

**Proposition 2.10** (Cauchy's Theorem): If prime $p$ divides $|G|$, then $G$ has an element of order $p$.

*Proof (using class equation):* For abelian $G$: decompose as product of cyclics; one factor has order divisible by $p$, which has a subgroup of order $p$. For non-abelian $G$: if $p \mid [G:C_G(x)]$ for all $x \in T$, then $p \mid |Z(G)|$ (abelian case applies). Otherwise $p \mid |C_G(x)|$ for some $x$ with $|C_G(x)| < |G|$; apply induction.

**Proposition 2.11**: If $G$ is non-abelian, then $G/Z(G)$ is not cyclic.

*Proof:* If $G/Z(G) = \langle aZ \rangle$, then any two elements $a^k y$ and $a^\ell z$ (with $y, z \in Z(G)$) commute, contradicting non-abelianness.

**Proposition 2.12**: $H \trianglelefteq G$ iff $H$ is a union of conjugacy classes.

**Normaliser**: $N_G(H) = \{g \in G : gH = Hg\}$; $H \trianglelefteq N_G(H)$; the number of subgroups conjugate to $H$ is $[G : N_G(H)]$.

#### §2.3 Conjugacy in Permutation Groups

**Proposition 2.13**: For $H \leq S_n$: either $H \subseteq A_n$ or $|H \cap A_n| = |H|/2$.

**Cycle type** of $\sigma$: $1^{m_1} 2^{m_2} \cdots n^{m_n}$ where $m_i$ = number of $i$-cycles.  
**Cycle index**: $\text{cyc}(\sigma) = \sum m_i$.

**Proposition 2.14**: $\pi\rho\pi^{-1} = (\pi(i_1)\ \pi(i_2)\ \cdots\ \pi(i_k))$ for $\rho = (i_1\ i_2\ \cdots\ i_k)$.

**Proposition 2.15**: Permutations are conjugate in $S_n$ iff they have the same cycle type.

*Proof:* Forward: conjugation preserves cycle lengths (by Prop 2.14). Backward: given same cycle types, construct $\pi$ by aligning cycles.

**Proposition 2.16** (conjugacy class sizes): The conjugacy class of $\sigma$ with cycle type $1^{m_1} \cdots n^{m_n}$ has $\frac{n!}{1^{m_1} 2^{m_2} \cdots n^{m_n} m_1! m_2! \cdots m_n!}$ elements. The centraliser has order $1^{m_1} 2^{m_2} \cdots n^{m_n} m_1! \cdots m_n!$

**Conjugacy in $A_n$**: A conjugacy class in $S_n$ either remains a single class in $A_n$ or splits into two equal halves. This is used to show **$A_5$ is simple** by checking that no non-trivial union of conjugacy classes (of size dividing 60) forms a subgroup.

#### §2.4 Burnside's Formula

**Proposition 2.17** (Burnside's Formula): Number of orbits = $\frac{1}{|G|} \sum_{g \in G} |\text{Fix}(g)|$.

*Proof:* Count pairs $(g, x)$ with $g(x) = x$ in two ways: $\sum |\text{Fix}(g)| = \sum |G_x|$. By orbit-stabiliser, $\sum |G_x|/|G| = \sum 1/|O(x)|$. Each orbit contributes $|O(x)|$ terms of $1/|O(x)|$, each equalling 1.

**Proposition 2.18** (Colouring formula): With $q$ colours and symmetry group $G \subseteq S_n$, the number of $q$-colourings is $\frac{1}{|G|} \sum_{\sigma \in G} q^{\text{cyc}(\sigma)}$.

**Example (hexagon, 3 colours):**
- Rotations only ($C_6$): $\frac{1}{6}(3^6 + 2 \cdot 3 + 2 \cdot 9 + 27) = 130$ colourings
- Rotations + reflections ($D_6$): $\frac{1}{12}(3^6 + 2 \cdot 3 + 2 \cdot 9 + 27 + 3 \cdot 81 + 3 \cdot 27) = 92$ colourings

#### §2.5 $p$-Groups and Sylow Theorems

**Proposition 2.19**: For a $p$-group $G$ acting on finite $X$: $|\text{Fix}(G)| \equiv |X| \pmod{p}$. Consequently, $Z(G)$ is non-trivial.

**Proposition 2.20**: For $p$-subgroup $H$: $[N_G(H) : H] \equiv [G : H] \pmod{p}$.

**Proposition 2.21** (Sylow Theorems): For $|G| = p^k m$ with $p \nmid m$:
1. $G$ has at least one $p$-Sylow (subgroup of order $p^k$)
2. Every $p$-subgroup is contained in a $p$-Sylow
3. All $p$-Sylows are conjugate
4. $w_p \equiv 1 \pmod{p}$ and $w_p \mid m$
5. The normaliser of any $p$-Sylow has index $w_p$

*Proof of (i) and (ii):* Inductive construction: start with a subgroup of order $p$ (Cauchy), then use Proposition 2.20 to show $p \mid [N_G(H) : H]$ for any proper $p$-subgroup $H$, giving a larger $p$-subgroup via the correspondence theorem.

*Proof of (iii):* $P'$ acts on $G/P$ with $|\text{Fix}(P')| \equiv m \pmod{p} \neq 0$. There exists $bP$ fixed by all of $P'$, forcing $P' \subseteq bPb^{-1}$; by equal order, $P' = bPb^{-1}$.

*Proof of (iv):* $w_p = [G : N_G(P)]$; let $q = [N_G(P) : P]$; then $qw_p = m$ so $w_p \mid m$. By Prop 2.20, $m = q + kp$, giving $w_p = 1 + kp/q$; since $p \nmid q$, we get $w_p \equiv 1 \pmod{p}$.

**Proposition 2.22**: (i) Unique $p$-Sylow iff normal. (ii) Abelian groups have unique $p$-Sylows. (iii) If all $p$-Sylows are unique, $G$ is the internal direct product of its Sylows.

**Proposition 2.23** (Groups of order $pq$): For primes $p > q$:
- Every abelian group of order $pq$ is cyclic ($\cong C_{pq}$)
- Non-abelian exists iff $q \mid (p-1)$; then unique up to isomorphism, with $w_p = 1$ and $w_q = p$

**Proposition 2.24**: If $H \trianglelefteq G$ is cyclic and $\varphi(|H|)$ is coprime to $|J|$, then $hj = jh$ for all $h \in H, j \in J$. In particular, if $\varphi(|H|)$ is coprime to $|G|$, then $H \subseteq Z(G)$.

*Proof:* The map $\theta: J \to \text{Aut}(H)$ by $j \mapsto \gamma_j$ is a homomorphism. Since $|\text{Aut}(H)| = \varphi(|H|)$ and $|J|$ are coprime, $|\theta(J)| = 1$, so conjugation by $j$ is trivial.

#### §2.6 Simple Groups

**Definition**: A simple group has no non-trivial proper normal subgroups.

**Proposition 2.25**: A finite abelian group is simple iff its order is prime.

**Proposition 2.26**: If $H \leq S_n$ is simple and $|H| > 2$, then $H \subseteq A_n$.

**Proposition 2.27**: Groups of order $2m$ ($m$ odd, $m > 1$) are not simple.

*Proof:* By Cayley's theorem, $G$ embeds in $S_{2m}$. An element of order 2 maps to a product of $m$ (odd number of) transpositions, hence is odd. So the embedding is not in $A_{2m}$, and by Prop 2.26, $G$ is not simple.

**Proposition 2.28**: $A_n$ is simple for all $n \geq 5$.

*Proof (by induction):* Base case $A_5$: using conjugacy class analysis (sizes 1, 12, 12, 15, 20 in one partition), no non-trivial union has order dividing 60. For $A_6$: $A_5$ embeds as a simple subgroup; any normal subgroup $N$ containing an element fixing some point must contain all 3-cycles (since they're conjugate in $A_6$), hence $N = A_6$. Elements fixing no point lead via commutator tricks to elements fixing a point. Inductive step for $n \geq 7$: same argument using $A_{n-1}$.

**Proposition 2.29**: If $G$ is simple with a subgroup of index $m$, then $|G| \mid m!$

This is used to find maximum subgroup orders in simple groups (e.g., simple group of order 1092 has no subgroup of order $> 84$).

**Uniqueness of $A_5$**: The notes prove that up to isomorphism, $A_5$ is the only simple group of order 60, by showing any such group embeds in $A_6$ with index 6, and then into $A_5$ via coset action.

### Chapter 3: Rings, Fields, Algebras

#### §3.1 Rings and Fields

**Definitions reviewed:**
- **Ring** $(R, +, \times)$: abelian group under $+$, semigroup under $\times$, distributive
- **Commutative ring, ring with unity, units, division ring, field**
- **Subring test**: $a - b \in S$ and $ab \in S$ for all $a, b \in S$

**Quaternions $\mathbb{H}$**: The ring of real quaternions $\{a + bi + cj + dk : a,b,c,d \in \mathbb{R}\}$ with $i^2 = j^2 = k^2 = -1$, $ij = k$, $jk = i$, $ki = j$ and anti-commutativity ($ji = -k$, etc.).

**Proposition 3.1**: $\mathbb{H}$ is a non-commutative division ring. Each non-zero $u$ has inverse $\frac{1}{\|u\|^2}\bar{u}$, where $\bar{u} = a - bi - cj - dk$ and $\|u\| = \sqrt{a^2 + b^2 + c^2 + d^2}$.

**Key properties:** $\overline{uv} = \bar{v}\bar{u}$; $\|uv\| = \|u\| \cdot \|v\|$.

**Proposition 3.2** (Euler's Four-Square Identity): $(a^2+b^2+c^2+d^2)(e^2+f^2+g^2+h^2) = w^2+x^2+y^2+z^2$ where $w,x,y,z$ are the coefficients of the quaternion product $(a+bi+cj+dk)(e+fi+gj+hk)$.

**Wedderburn's Theorem** (stated): Every finite division ring is a field.

#### §3.2 Ideals and Ring Decompositions

**Ideals**: Left ideal ($ra \in I$), right ideal ($ar \in I$), two-sided ideal (both).  
**Simple ring**: No non-trivial proper two-sided ideals.

**Proposition 3.3**: $M_n(D)$ is a simple ring for any division ring $D$.

*Proof:* Any non-zero element $A$ in an ideal $J$ has some entry $a_{rs} \neq 0$ (invertible in $D$). Using elementary matrices: $a_{rs}^{-1} E_{ir} A E_{sj} = E_{ij}$, so all $E_{ij} \in J$, hence $I_n \in J$ and $J = M_n(D)$.

**Idempotents**: $e^2 = e$. Central: $er = re\ \forall r$. Orthogonal: $ef = fe = 0$. Primitive: cannot be written as sum of two non-zero orthogonal idempotents.

**Proposition 3.4**: If $e$ is idempotent, so is $1 - e$, and they are orthogonal.

**Proposition 3.5**: If an ideal $I$ has its own unity $e$, then $e$ is a central idempotent and $I = eR$.

**Proposition 3.6** (Ring direct sum): If $R = I + J$ and $I \cap J = \{0\}$, then $R \cong I \times J$.

**Proposition 3.7**: For a central idempotent $e$: $R = eR \oplus (1-e)R$.

#### §3.3 Algebras

**Definition**: A $K$-algebra $A$ is a vector space over field $K$ with bilinear multiplication. Associative, with unity, division algebra, subalgebra, ideal, simple algebra defined.

**Key examples:**
- $\mathbb{R}$, $\mathbb{C}$: division algebras over $\mathbb{R}$
- $M_n(K)$: $n^2$-dimensional algebra over $K$
- $\mathbb{H}$: 4-dimensional non-commutative division algebra over $\mathbb{R}$
- $M_n(D)$ is simple for division algebra $D$

**Proposition 3.8** (Regular Representation): Every $n$-dimensional associative algebra with unity over $K$ is isomorphic to a subalgebra of $M_n(K)$.

*Proof:* Define $\lambda_x: a \mapsto xa$ (left multiplication). The map $\theta: x \mapsto C_x$ (matrix of $\lambda_x$) is an injective algebra homomorphism.

**Group algebras** $KG$: For finite group $G = \{x_1, \ldots, x_n\}$ and field $K$, $KG = \{\sum a_i x_i : a_i \in K\}$ with multiplication extended from $G$ distributively.

**Proposition 3.9**: Let $e = \frac{1}{|G|} \sum_{x \in G} x$. Then $e$ is a central idempotent in $KG$, giving $KG = eKG \oplus (1-e)KG$ with $\dim_K(eKG) = 1$.

*Proof:* $x_i e = e$ for each $x_i$ (since $x_i$ permutes $G$). Then $e^2 = \frac{1}{n}(x_1 e + \cdots + x_n e) = \frac{1}{n}(ne) = e$. The ideal $eKG = \text{span}_K\{e\}$ has dimension 1.

**Key results proved:**

**Key results:**

4. **Q11**: $G$ acts transitively iff $O(x) = X$ for all $x$. If $G$ acts transitively on itself, $G_x = \{e\}$ for all $x$.
5. **Q12**: $g(x) = gxg^{-1}$ defines conjugation action. $\widetilde{G}_G = \text{Fix}(G) = Z(G)$.
6. **Q16**: $p$-group acting on $X$: orbits have order 1 or $p$; if $p \mid |X|$ then $p \mid |\text{Fix}(G)|$.
7. **Q17** (Cauchy's Theorem via group actions): Considers the set $X$ of tuples $(a_0, \ldots, a_{p-1})$ with $\prod a_r = e$; $C_p$ acts by cyclic permutation. $|\text{Fix}(C_p)| \equiv |X| = |G|^{p-1} \equiv 0 \pmod{p}$. Fixed points are $(a, a, \ldots, a)$ with $a^p = e$; at least $p$ such elements exist (including $e$), giving $p - 1$ elements of order $p$.

### AA-Ex2.6-Ans (Exercises 2.6 — Simple Groups)

**Topics:** Simple group analysis, non-existence proofs, Sylow-based arguments.

**Key results:**
